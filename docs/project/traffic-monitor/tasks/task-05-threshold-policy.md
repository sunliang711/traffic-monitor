# 任务 05：阈值配置模块实现

## 任务描述与目标

实现全局阈值和单机覆盖阈值配置，支持小时/日、上行/下行/总流量维度，统一阈值单位换算。

## 技术方案

- 数据库存储统一转换为 `MB`
- UI 层允许输入 `MB/GB`
- 读取阈值时优先单机覆盖，否则回退全局阈值

## 验收标准

- 可配置全局阈值
- 可为单机配置覆盖阈值
- 系统正确处理 `MB/GB` 换算
- 未配置单机阈值时自动继承全局阈值

## 实现步骤指引

1. 设计阈值规则表
2. 实现单位转换工具
3. 实现阈值查询与覆盖逻辑
4. 提供全局和单机配置接口

## 前置依赖与风险

- 前置依赖：任务 04
- 风险：规则维度较多，表结构和 API 设计需要保持清晰

# 任务 07：调度器与并发控制实现

## 任务描述与目标

实现定时调度、任务分发、并发 worker pool、超时和重试机制，支撑可配置规模的机器采集。

## 技术方案

- 使用 `Fx Lifecycle` 管理调度器生命周期
- 调度周期从配置读取
- 使用固定上限 worker pool 控制并发
- 单任务支持超时和有限重试

## 验收标准

- 可按配置频率执行采集
- 任务不会无限并发增长
- 支持失败重试
- 服务关闭时调度器可优雅退出

## 实现步骤指引

1. 设计调度配置模型
2. 实现周期触发器
3. 实现 worker pool
4. 接入超时和重试策略
5. 增加手动触发采集入口

## 前置依赖与风险

- 前置依赖：任务 06
- 风险：并发和重试组合不当会导致远程机器瞬时压力过高

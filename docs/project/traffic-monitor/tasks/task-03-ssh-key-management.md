# 任务 03：SSH Key 管理与密钥加密实现

## 任务描述与目标

实现 SSH 私钥管理能力，支持导入已有私钥和系统生成 keypair，并确保私钥以加密形式存储。

## 技术方案

- 通过 `APP_MASTER_KEY` 作为主密钥加密私钥
- `ssh_keys` 表保存私钥密文、公钥和指纹
- 提供导入私钥接口和生成 keypair 接口
- 生成 keypair 时返回可部署的公钥内容

## 验收标准

- 支持导入合法私钥
- 支持生成新的 keypair
- 私钥不以明文写入数据库和日志
- 可以通过指纹识别 key

## 实现步骤指引

1. 设计 `ssh_keys` 表
2. 实现主密钥读取与加解密工具
3. 实现私钥导入校验
4. 实现 keypair 生成功能
5. 提供 SSH Key CRUD 接口

## 前置依赖与风险

- 前置依赖：任务 01
- 风险：主密钥长度、编码方式和轮换策略需要统一约束

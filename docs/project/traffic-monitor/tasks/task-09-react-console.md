# 任务 09：React 管理界面实现

## 任务描述与目标

实现 MVP 所需的 React 管理后台，覆盖登录、机器管理、阈值配置、渠道配置、采集记录和告警记录。

## 技术方案

- 使用 `React + Vite`
- 页面按模块拆分，接口通过统一 API Client 调用
- UI 保持轻量，优先满足管理效率
- 构建产物输出到后端可嵌入目录

## 验收标准

- 可完成登录和退出
- 可完成机器、SSH Key、阈值和通知配置
- 可查看最近采集记录和告警记录
- 能通过后端内嵌静态资源访问页面

## 实现步骤指引

1. 初始化 React 工程和路由
2. 搭建登录态管理
3. 实现 Dashboard 和列表页
4. 实现配置编辑表单
5. 对接后端 API

## 前置依赖与风险

- 前置依赖：任务 02、任务 04、任务 05、任务 08
- 风险：表单维度较多，需要统一状态管理和错误展示

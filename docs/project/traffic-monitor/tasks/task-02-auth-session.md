# 任务 02：认证与 Session 模块实现

## 任务描述与目标

实现管理员账号密码登录、登出、鉴权中间件和初始管理员引导能力，为后续管理接口提供统一认证机制。

## 技术方案

- 密码使用 `bcrypt` 哈希
- 登录成功后写入 `HttpOnly` Cookie Session
- 中间件统一保护受限 API
- 启动时根据环境变量创建初始管理员

## 验收标准

- 支持登录和登出
- 未登录请求受保护接口返回未认证
- 初始管理员可通过环境变量自动初始化
- 不在日志和响应中泄露敏感信息

## 实现步骤指引

1. 设计 `admins` 表和管理员模型
2. 实现密码哈希和校验逻辑
3. 实现 Session 创建、校验和销毁
4. 接入鉴权中间件
5. 实现初始管理员初始化流程

## 前置依赖与风险

- 前置依赖：任务 01
- 风险：Session 密钥配置不当会导致登录态失效

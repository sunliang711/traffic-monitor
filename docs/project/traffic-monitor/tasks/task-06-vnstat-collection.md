# 任务 06：`vnstat` 采集、解析与持久化实现

## 任务描述与目标

实现通过 SSH 执行 `vnstat`、解析结果并保存小时和日流量样本，为告警判定提供数据基础。

## 技术方案

- 优先使用 `vnstat --json`
- 按指定网卡采集
- 解析结果后分别写入小时样本和日样本
- 保存原始 payload 以便后续排查

## 验收标准

- 能成功从远程机器采集小时和日流量
- 支持上行、下行和总流量解析
- 采集失败有结构化错误日志
- 样本数据可查询

## 实现步骤指引

1. 设计采集结果模型
2. 编写 `vnstat` JSON 解析器
3. 实现 SSH 命令执行器
4. 实现样本入库逻辑
5. 为失败场景补充错误分类

## 前置依赖与风险

- 前置依赖：任务 04
- 风险：`vnstat` 输出版本兼容性需要验证

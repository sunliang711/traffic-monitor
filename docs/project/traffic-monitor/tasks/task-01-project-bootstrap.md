# 任务 01：项目脚手架与基础设施搭建

## 任务描述与目标

完成后端与前端项目骨架初始化，建立符合 Go 分层规范的目录结构、基础配置加载、日志初始化、数据库连接初始化和前端构建嵌入链路。

## 技术方案

- 后端采用 `Gin + Fx + GORM + Viper + Zerolog`
- 前端采用 `React + Vite`
- 预留 `web/dist` 作为前端构建产物目录，供 `Go embed` 引用
- 启动阶段完成配置加载、日志初始化、数据库连接和自动 migrate 入口装配

## 验收标准

- 可以启动空白 HTTP 服务
- 可以成功连接 PostgreSQL
- 前端可完成本地构建并由后端提供静态资源
- 项目目录结构满足 `Handler -> Service -> Repository -> Model/DTO`

## 实现步骤指引

1. 初始化 `go.mod` 和前端工程
2. 建立 `cmd/`、`internal/`、`config/`、`web/` 目录
3. 接入 `Fx` 生命周期
4. 完成基础配置结构体与环境变量加载
5. 接入 `Zerolog` 和 HTTP 基础路由
6. 打通前端构建与 `embed` 流程

## 前置依赖与风险

- 前置依赖：无
- 风险：前后端构建链路耦合，需要尽早统一目录结构

# 任务 04：机器管理与 SSH 连通性测试

## 任务描述与目标

实现远程机器管理能力，包括机器增删改查、指定网卡配置、SSH Key 绑定和连接测试。

## 技术方案

- `machines` 表保存主机、端口、用户、网卡和启用状态
- 机器与 `ssh_keys` 建立关联
- 提供连接测试接口，验证 SSH 可用性和 `vnstat` 可执行性

## 验收标准

- 可以管理机器列表
- 每台机器必须指定一个网卡
- 可测试 SSH 登录和命令执行
- 无效配置有明确校验错误

## 实现步骤指引

1. 设计 `machines` 表
2. 实现机器 CRUD 接口
3. 实现 SSH 连接测试服务
4. 增加对 `vnstat` 命令存在性的校验

## 前置依赖与风险

- 前置依赖：任务 03
- 风险：不同机器的 shell 环境差异可能影响命令测试结果

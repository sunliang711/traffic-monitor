# 任务 10：Docker 交付与初始化配置完善

## 任务描述与目标

完成镜像构建、容器启动配置、环境变量说明和本地联调方案，确保项目可以以 Docker 方式部署运行。

## 技术方案

- 使用多阶段构建
- 前端在构建阶段打包后嵌入后端二进制
- 提供 `docker-compose.yml`
- 用环境变量注入数据库、Session、主密钥和管理员初始化参数

## 验收标准

- 可通过 Docker 构建镜像
- 可通过 `docker-compose` 启动服务与 PostgreSQL
- 首次启动能自动 migrate 并初始化管理员
- 文档包含必需环境变量说明

## 实现步骤指引

1. 编写 Dockerfile
2. 编写 `docker-compose.yml`
3. 整理环境变量示例
4. 验证启动自动 migrate
5. 补充部署说明

## 前置依赖与风险

- 前置依赖：任务 01 至任务 09
- 风险：镜像构建链路包含前端和后端，需控制缓存与产物路径

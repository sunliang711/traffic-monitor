# 任务 08：告警判定与去重通知实现

## 任务描述与目标

实现小时/日维度的阈值判定、去重告警、通知发送和投递记录。

## 技术方案

- 告警判定支持 `upload`、`download`、`total`
- 使用 `machine_id + period_type + metric_type + bucket_time` 生成唯一 `alert_key`
- 命中阈值后写入 `alerts` 表，再按启用渠道发送
- 未启用任何渠道时标记 `skipped` 并记录日志

## 验收标准

- 小时超限同一小时只通知一次
- 日超限同一天只通知一次
- 支持 `Webhook` 和 `Telegram`
- 有完整发送记录和失败记录

## 实现步骤指引

1. 设计告警表和投递记录表
2. 实现阈值判定器
3. 实现去重键和唯一索引
4. 实现 `Webhook` 发送器
5. 实现 `Telegram` 发送器
6. 统一投递结果记录

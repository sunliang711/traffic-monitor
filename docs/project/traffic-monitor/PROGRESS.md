## 当前决策摘要

- 后端：`Go`
- 前端：`React + Vite`
- 数据库：`PostgreSQL`
- 鉴权：`Cookie Session`
- SSH：仅支持 `key` 登录
- SSH Key：支持导入已有 key 和系统生成 keypair
- 采集命令：远程执行 `vnstat`
- 阈值维度：小时/日、上行/下行/总流量
- 通知：`Webhook`、`Telegram`
- 启动行为：自动 migrate
- 主密钥：通过环境变量注入
- 恢复通知：不做
